# ADR 0002 — Refuerzo MASW-R1 sin heredar aprobación experimental

Fecha: 2026-10-12. Estado: incorporado como suplemento documental.

La revisión externa mezcla brechas reales con exigencias ya implementadas y
criterios no defendibles universalmente. Se incorpora el [anexo D y evaluación](../masw_review_2026_10_12.md)
con ocho obligaciones registradas en [el suplemento](../validation_masw_r1.json).

Se conserva el alcance QC diagnóstico y la referencia ingenieril offline para
Vs30. No se exige una inversión de producción ni detección universal de modos
leaky. Se formalizan forward/dominio, identidad modal verificable, covarianza
conjunta, resolución local, incertidumbre por clase y propagación hasta el objetivo.

Fundamento matemático: el determinante cambia al escalar estados sin cambiar
raíces; kr es exactamente 2πr/λ; R y la covarianza de ruido del estimador no son
incertidumbre total. Una medida de anchura debe declarar base, unidades y
normalización. Las derivaciones y fuentes están en D.1–D.6; no se adoptan nuevos
umbrales empíricos ni se relajan tolerancias existentes.

Se conserva el manifiesto base con sus 100 IDs y la evidencia histórica. El
suplemento tiene revisión MASW-R1, estados NOT_RUN y cierre separado, que no
hereda PASSED del G5 anterior. RM-08 exige migrar runner/contratos y vincular
revisión/hash antes de cualquier cierre ampliado. El esquema runtime actual no
se modifica mediante esta edición documental.

Consecuencia: el desarrollo diagnóstico puede continuar; integración de decisión
y nueva suficiencia científica deben cubrir las obligaciones afectadas. G9 y las
decisiones de campo siguen pendientes. No se modifica código de producto en esta revisión.
